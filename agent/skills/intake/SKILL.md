# Intake

A short intake procedure is already in standing instructions. Use this only for the full checklist.

This is for capturing a person, request, or project — work or personal. Do not assume it is a sales lead.

1. Collect who it is for (themselves, a household, a team, a client, or someone else), names and roles if useful, contact info if it matters, dates or flexibility, budget band if money is involved, desired outcome, and hard constraints.
2. Ask only for missing facts. Do not invent a profile.
3. If they are deciding whether to take work, hire someone, or commit money, add fit notes: budget vs. scope, timing, and who decides. For a personal plan, skip that and just lock the brief.
4. Return a one-screen brief: snapshot, missing facts, recommended next step.
5. Then offer to `create_document` with the brief as a markdown file. Do not save before they have seen the brief unless they already asked to file it. Do not put this in sticky-note memory.

## Quick start

If the user invoked this skill with `/intake` and no extra brief, say you will run intake, then ask who it is for, dates or flexibility, budget if relevant, desired outcome, and hard constraints. Do not invent a profile. Once they answer, follow the checklist above.
