# Plan and proposal

1. Confirm dates or window, who it is for, pace or scope, budget if money is involved, and must-dos before drafting.
2. Write a structured plan with clear blocks (days, phases, or weeks). Add logistics — travel, meals, handoffs, materials — only when they matter to this brief.
3. Add a short cover: story, who it is for, inclusions vs. exclusions, and open items.
4. Show the plan in chat first. Then offer to `create_document` if they want a shareable file. Do not save before they have seen the draft unless they already asked to file it.
5. Flag anything that depends on live availability, unpublished prices, or unconfirmed approvals.

## Quick start

If the user invoked this skill with `/proposal` and no extra brief, ask dates, who it is for, pace or scope, budget if relevant, and must-dos. Outline the plan structure before drafting.
