# Brainstorming

A short brainstorm procedure is already in standing instructions. Load this only for the full question bank and angle template.

Works for work or personal ideas. Do not dump a list of popular options. Question first, then offer a few distinct angles they could not get from a template.

1. Restate the brief in one line (who, when, vibe, constraint). If that line is empty, ask for the missing piece before ideating.
2. Ask 3–5 follow-ups that unlock motivation, a constraint, or a surprise — not facts they already answered. Dig one layer past the first answer (why that goal, what "simple" means, whose project this really is).
3. After they answer — or if they want ideas now — return 3–5 distinct angles. Each must name:
   - **Insight** — what you noticed that is not obvious
   - **Value** — why the audience (or the outcome) is better for it
   - **Novelty** — how this is not a generic version of the same idea
4. Mark each angle `ready`, `needs research`, or `needs a partner`. Do not invent availability, prices, or legal constraints. Load `research` only after an angle is worth checking.
5. Close with the strongest recommendation and one next step: more questions, research, `write-rewrite`, or `proposal`.

## Follow-up questions

Prefer questions that change the work, not ones that fill a form:

- What would make this feel like the right choice later?
- What should this feel like on day two — not just get done?
- Whose preferences win if people disagree?
- What have they already tried that we should not repeat?
- Where is the budget actually tight: time, money, energy, or people?

Skip intake fields (names, party size, dates, budget band) unless they are still unknown — then collect them and load `lead-intake` if this is a new person or request.

## Angle template

```markdown
### [Angle name]
- Insight: …
- Value: …
- Novelty: …
- Status: ready | needs research | needs a partner
```

## Gotchas

- Novelty without a path to ship is a mood board. Prefer ideas this user can actually do.
- If the brief is locked, refine it. Do not reopen every decision.
- "Unique" is specific (a constraint, a timing window, a need) — not "think outside the box."
- After brainstorming, do not pretend the idea is confirmed. Hand off to research or writing.

## Quick start

If the user invoked this skill with `/brainstorming` and no extra brief, ask what they want to explore and one constraint or audience (including themselves). Restate a one-line brief, then ask 3–5 follow-ups before ideating.
